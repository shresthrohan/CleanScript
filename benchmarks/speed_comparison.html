How long does it take to clean a messy CSV?

The same cleaning job (dedupe, fill missing values, drop a column, two filters, normalize, rename, sort) on CSVs from 10 to 1,000,000 rows. CleanScript times are measured. The cloud LLM and online cleaner times are modeled from the real file sizes.

Time to clean, by file size

Log scale: each gridline step is about 10× or more. The row counts are spaced evenly, not to scale. Hover or tab to a point for exact values.

Side by side

CleanScript numbers are the median warm run (read CSV → compile → execute → write CSV) with the app already running. In a brand-new Python process, including start-up and imports, they were 1.69 s, 1.55 s, 2.28 s and 8.97 s.

Cloud LLM (modeled)

  • 3 characters per token, from the real input and output files
  • 200k context, 32k output tokens per request
  • 1 s to first token, 5,000 tokens/s reading, 60 tokens/s writing
  • Above 100 rows the file is split across requests, so no request sees the whole dataset

Online CSV cleaner (modeled lower bound)

  • Upload at 10 Mbit/s, download at 50 Mbit/s
  • 1 s fixed for the page and request round trips
  • Counts zero seconds for the tool's own processing and for clicking through its UI
  • No specific product was tested; the real time can only be longer
